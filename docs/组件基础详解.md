## 组件概述

React 组件是构建用户界面的基本单元。组件让你可以将 UI 拆分为独立可复用的代码片段，并对每个片段进行独立构思。

### 组件的特点
- **封装性**: 组件封装了状态和逻辑
- **可复用性**: 同一个组件可以在多处使用
- **可组合性**: 小组件可以组合成大组件
- **独立性**: 组件有自己的生命周期和状态

## 函数组件

函数组件是定义组件的最简洁方式。

### 基本语法
```typescript
// 最简单的函数组件
const Welcome = () => {
  return <h1>Hello, World!</h1>
}

// 带 props 的函数组件
const Greeting = (props: { name: string }) => {
  return <h1>Hello, {props.name}!</h1>
}

// 使用解构赋值
const GreetingWithDestructuring = ({ name }: { name: string }) => {
  return <h1>Hello, {name}!</h1>
}
```

## 类组件

虽然函数组件是现代 React 的主流，但理解类组件仍然很重要。

### 基本语法
```typescript
import React, { Component } from 'react'

interface Props {
  name: string
  age?: number
}

interface State {
  count: number
}

class ClassComponent extends Component<Props, State> {
  constructor(props: Props) {
    super(props)
    this.state = {
      count: 0
    }
  }

  handleClick = () => {
    this.setState({ count: this.state.count + 1 })
  }

  render() {
    const { name, age } = this.props
    const { count } = this.state

    return (
      <div>
        <h3>Hello, {name}!</h3>
        {age && <p>年龄: {age}</p>}
        <p>点击次数: {count}</p>
        <button onClick={this.handleClick}>点击我</button>
      </div>
    )
  }
}
```

### 生命周期方法
```typescript
class LifecycleComponent extends Component<Props, State> {
  componentDidMount() {
    console.log('组件挂载完成')
    // 获取数据、设置订阅等
  }

  componentDidUpdate(prevProps: Props, prevState: State) {
    console.log('组件更新完成')
    // 比较 props 或 state 的变化
  }

  componentWillUnmount() {
    console.log('组件即将卸载')
    // 清理定时器、取消订阅等
  }

  render() {
    return <div>生命周期演示</div>
  }
}
```

## JSX 详解

JSX 是 JavaScript 的语法扩展，让你可以在 JavaScript 中编写类似 HTML 的代码。

### JSX 基本规则
```typescript
const JSXRules = () => {
  const name = "React"
  const isLoggedIn = true
  const users = ["Alice", "Bob", "Charlie"]

  return (
    <div>
      {/* 1. 必须有一个根元素 */}
      <div className="container">
        
        {/* 2. 使用 className 而不是 class */}
        <h1 className="title">欢迎来到 {name}</h1>
        
        {/* 3. 使用 htmlFor 而不是 for */}
        <label htmlFor="username">用户名</label>
        <input id="username" type="text" />
        
        {/* 4. 自闭合标签必须以 /> 结尾 */}
        <img src="avatar.jpg" alt="头像" />
        <br />
        
        {/* 5. JavaScript 表达式用 {} 包裹 */}
        <p>当前时间: {new Date().toLocaleString()}</p>
        <p>计算结果: {2 + 3}</p>
        
        {/* 6. 条件渲染 */}
        {isLoggedIn ? <p>欢迎回来!</p> : <p>请登录</p>}
        {isLoggedIn && <button>退出登录</button>}
        
        {/* 7. 列表渲染 */}
        <ul>
          {users.map((user, index) => (
            <li key={index}>{user}</li>
          ))}
        </ul>
        
        {/* 8. 内联样式 */}
        <div style={{ 
          backgroundColor: 'blue', 
          color: 'white', 
          padding: '10px' 
        }}>
          内联样式示例
        </div>
      </div>
    </div>
  )
}
```

### JSX 中的事件处理

## Props 深入理解

Props 是组件间传递数据的方式，类似于函数的参数。

### Props 的特点
- **只读性**: Props 是只读的，不能修改
- **单向数据流**: 数据从父组件流向子组件
- **类型安全**: 使用 TypeScript 可以确保类型安全

### 复杂 Props 示例
```typescript
interface User {
  id: number
  name: string
  email: string
  avatar?: string
  preferences: {
    theme: 'light' | 'dark'
    language: string
  }
}

interface UserProfileProps {
  user: User
  onEdit: (userId: number) => void
  onDelete: (userId: number) => void
  showActions?: boolean
}

const UserProfile: React.FC<UserProfileProps> = ({ 
  user, 
  onEdit, 
  onDelete, 
  showActions = true 
}) => {
  return (
    <div className="user-profile">
      {user.avatar && (
        <img src={user.avatar} alt={`${user.name}的头像`} />
      )}
      <div className="user-info">
        <h3>{user.name}</h3>
        <p>{user.email}</p>
        <p>主题: {user.preferences.theme}</p>
        <p>语言: {user.preferences.language}</p>
      </div>
      {showActions && (
        <div className="actions">
          <button onClick={() => onEdit(user.id)}>编辑</button>
          <button onClick={() => onDelete(user.id)}>删除</button>
        </div>
      )}
    </div>
  )
}
```

## 组件组合

React 鼓励组合而不是继承来实现代码复用。

### 组合示例
```typescript
// 基础按钮组件
const BaseButton: React.FC<{
  children: React.ReactNode
  onClick?: () => void
  disabled?: boolean
}> = ({ children, onClick, disabled }) => {
  return (
    <button onClick={onClick} disabled={disabled}>
      {children}
    </button>
  )
}

// 图标按钮组件
const IconButton: React.FC<{
  icon: string
  text: string
  onClick?: () => void
}> = ({ icon, text, onClick }) => {
  return (
    <BaseButton onClick={onClick}>
      <span className="icon">{icon}</span>
      <span>{text}</span>
    </BaseButton>
  )
}

// 确认按钮组件
const ConfirmButton: React.FC<{
  text: string
  onConfirm: () => void
}> = ({ text, onConfirm }) => {
  const handleClick = () => {
    if (window.confirm('确定要执行此操作吗？')) {
      onConfirm()
    }
  }

  return <BaseButton onClick={handleClick}>{text}</BaseButton>
}
```

### 高阶组件模式（仅了解）
```typescript
// 高阶组件：为组件添加加载状态
function withLoading<P extends object>(
  Component: React.ComponentType<P>
) {
  return function WithLoadingComponent(props: P & { isLoading: boolean }) {
    const { isLoading, ...componentProps } = props
    
    if (isLoading) {
      return <div>加载中...</div>
    }
    
    return <Component {...componentProps as P} />
  }
}

// 使用高阶组件
const UserListWithLoading = withLoading(UserProfile)
```

## 常见问题和最佳实践

### 组件命名
- 使用 PascalCase（大驼峰）命名
- 名字应该描述组件的功能
- 避免过于通用的名字

### Props 设计
- 保持 props 接口简洁
- 使用 TypeScript 确保类型安全
- 提供合理的默认值
- 考虑组件的可扩展性

### 性能考虑
- 避免在 render 中创建新对象
- 合理使用 React.memo
- 将复杂计算提取到组件外部

这就是 React 组件的基础知识！通过练习和实践，您将更好地掌握这些概念。
